# AI Content Studio

## Overview
AI Content Studio is a multi-modal generative AI platform developed in Google Colab using Python and transformer-based AI models. The system automates content creation workflows including AI-generated text, images, voiceovers, branding assets, and marketing campaigns.

The project demonstrates practical applications of:
- Generative AI
- Prompt Engineering
- AI Automation
- AI Content Generation
- Multimodal AI Systems
- Marketing AI
- AI-Assisted Branding

---

# Features

- AI text generation for blogs, ads, captions, and campaigns
- AI image generation using Stable Diffusion
- AI voice generation using Text-to-Speech
- AI video generation using MoviePy
- Branding and slogan generation
- Marketing campaign automation
- Interactive Gradio UI
- GitHub integration support

---

# Technologies Used

- Python
- Transformers
- Stable Diffusion
- Gradio
- PyTorch
- MoviePy
- gTTS
- Hugging Face Models

```text
Runtime → Change runtime type → GPU
```
